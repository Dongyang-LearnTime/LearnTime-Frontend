# 토론방 검증

## 회귀 테스트

`npm run test:forum` 또는 `node --test tests/studyForum.test.mjs`를 실행합니다.
신규 메시지의 페이지 초과, 삭제/차단 반영, 경계 ID 삭제, 중복 ID, 반복 커서,
중간 요청 실패, 갱신 시 과거 메시지의 불필요한 추가를 검증합니다.

## 브라우저 검증 화면

개발 서버 실행 후 `/tests/forum-preview.html`을 엽니다.
실제 토론방 컴포넌트에 메모리상의 Axios 어댑터를 연결하며, 백엔드 요청이나 로그인은 하지 않습니다.
새로고침하면 65개의 테스트 메시지와 활동 중인 멤버 상태로 초기화됩니다.
이 진입점은 프로덕션 앱 라우트와 빌드 진입점에 포함되지 않습니다.

- 이전 메시지 더 보기: 30개 → 60개. 새로고침해도 60개를 유지합니다.
- 작성: 일반 텍스트 및 줄바꿈, 1,000자 제한, 성공 후 입력 초기화.
- 삭제: 본인 메시지에만 버튼, 확인창 취소/삭제와 목록 제거.
- 네트워크 실패 전환: 전송 실패 시 입력 보존 및 재시도.
- 수료 상태로 변경 후 새로고침: 읽기 전용. 전송 직전에 변경하면 403 응답으로 전환.
- 탈퇴 상태로 변경 후 새로고침: 목록 제거와 접근 불가 안내.
- 테마 전환 및 모바일 폭: 입력창과 메시지의 가로 넘침 확인.

이 화면은 UI와 클라이언트 동작만 검증합니다. 실제 JWT 갱신, 두 계정 간 대화,
서버의 차단 필터 및 DB 마이그레이션은 실행 중인 백엔드와 별도로 검증해야 합니다.
